# AGENTS.md - Project Context for OpenCode

## Project Overview

**pyGoogleMoogle** is a serverless Slack bot that responds to @mentions and slash commands with witty Final Fantasy Moogle-style responses powered by OpenAI.

### Key Architecture
- **API Gateway**: `/googlemoogle/events`, `/googlemoogle/slash`, `/googlemoogle/health`
- **API Key**: Auto-generated by AWS (not manual) via usage plan
- **Authorizer**: Lambda authorizer validates `api_key` query parameter (simplified - Slack signatures moved to Initial Lambda)
- **Initial Lambda**: Validates Slack signatures, posts immediate "thinking" messages via `chat.postMessage`, sends to SQS
- **Processing Lambda**: Handles OpenAI calls, posts final responses via `chat.postMessage`
- **SQS Queue**: Async processing (no DLQ configured)
- **Remote State**: Terraform uses S3 + DynamoDB backend

### AWS Tags
All resources tagged with: `appname=slackbotGoogleMoogle`

## Technical Discoveries

- **x-api-key naming conflict**: `x-api-key` appears to be a reserved name in AWS API Gateway. When used as query parameter, it may be filtered/stripped before reaching Lambda authorizer. Using `api_key` works fine. Debug logging added to investigate.
- **Critical idempotency bug fixed**: Original `generate_request_id()` used `time.time()` as fallback. Fixed to use Slack's stable `event_id` and `trigger_id`.
- **API Gateway Authorizer IAM**: API Gateway needs separate IAM role with trust policy allowing `apigateway.amazonaws.com` to assume it.
- **Terraform Deployment Caching**: API Gateway deployments are immutable. Used `create_before_destroy` lifecycle and deployment triggers to force redeployment.

## Key Design Decisions

1. **Idempotency**: Uses Slack's `event_id` (events API) and `trigger_id` (slash commands) - NOT `time.time()`
2. **Authorizer**: Only validates API key. Slack signatures validated in Initial Lambda.
3. **Response Method**: Both @mentions and slash commands use `chat.postMessage` Web API (no `response_url`)
4. **API Key Location**: Query parameter `?api_key=XXX` (header-based `x-api-key` has conflicts with API Gateway)
5. **Logging**: Default ERROR level for minimal CloudWatch costs. Set to DEBUG temporarily for troubleshooting.
